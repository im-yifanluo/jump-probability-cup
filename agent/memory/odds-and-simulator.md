Two upgrades built 2026-06-14 (after research confirmed market-anchoring is SOTA but Monte Carlo simulation is the industry SOTA for derived markets):

POLYMARKET ODDS BLEND (src/wcdata/polymarket.py): Polymarket Gamma API (https://gamma-api.polymarket.com/events?tag_slug=soccer) has WC match 1X2 markets — liquid ($1-3M volume), tiny ~0.3% overround, agrees tightly with DraftKings (NED vs JPN both ~0.477/0.266/0.256). No totals for WC games. price_match.get_anchors now blends de-margined Polymarket + ESPN/DraftKings 1X2 (50/50 average), keeps ESPN totals, flags >0.10 disagreement as stale-odds risk. fetch_match_1x2(home_full, away_full) returns PolymarketOdds or None (falls back to ESPN-only).

MONTE CARLO SIMULATOR (src/models/simulator.py + sim_pricer.py): plays each match minute-by-minute (~40k sims), tracks score, generates correlated derived stats conditioned on game state. Fixes the analytic model's blind spot — a leading favorite cedes 2nd-half shots/corners (the Haiti vs SCO failure mode). Anchoring preserved: goal rates from odds lambdas, count means + measured half-shares from CountPricer, game-state multiplier exp(-BETA*lead) NORMALIZED mean-preserving (only redistributes, marginals stay matched). POSSESSION_BETA=0.20. Validated: marginals match odds (1X2/totals), derived markets match analytic within MC noise (max ~0.03), tests/test_simulator.py. Use build_sim_pricer() / SimMatchPricer; not yet wired as the live default. HONEST finding: simulator AGREES with analytic on ~everything (the analytic model was already well-calibrated per 314-match StatsBomb validation), so benefit is a modest correct refinement (2H possession ~0.20→0.22, captures correlations), NOT a big jump. MEASURED head-to-head 2026-06-14 (314 StatsBomb matches, scored vs actual outcomes on the game-state-sensitive 2nd-half head-to-head markets): simulator beats analytic by only +0.0008 Brier (SOT 2H) / +0.0004 (corners 2H) — statistically a tie, within MC noise. So the Monte Carlo does NOT measurably outperform; we keep the analytic model as primary (faster, deterministic, no MC noise, equally accurate). DEEP REASON it can't help: Brier scores each market on its MARGINAL probability independently. The simulator's only real advantage over the analytic model is modeling the JOINT distribution (cross-market correlations) — which is irrelevant to independent-Brier scoring. The analytic model already nails the marginals (per 314-match StatsBomb validation), so there's nothing left for simulation to win. Compute is not the constraint — accuracy is, and there's no accuracy gain. The simulator stands as a validated SOTA-architecture reference that CONFIRMS the analytic model, not a replacement. Two bugs found+fixed during build: game-state not mean-preserving (favorite marginal dropped 5%), card late-ramp inflated total cards 30% — both fixed by mean-preserving normalization + measured per-stat half-share weighting.
